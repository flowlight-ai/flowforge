# Contributing to flowforge / 贡献指南

[English](#english) | [中文](#中文)

---

## English

### Before You Start
- Read [README.md](./README.md)
- Check existing [Issues](https://github.com/flowlight-ai/flowforge/issues)
- Join [Discussions](https://github.com/flowlight-ai/flowforge/discussions)

### Workflow
1. Fork the repository
2. Create a feature branch: `git checkout -b feat/your-feature`
3. Make changes and test
4. Commit: `git commit -m "feat: description"`
5. Push: `git push origin feat/your-feature`
6. Open a Pull Request (Gitee: dev->master branch)

### Commit Convention
- `feat:` new feature
- `fix:` bug fix
- `docs:` documentation
- `ci:` CI/CD changes
- `refactor:` code restructuring
- `test:` tests

## 中文

### 开始之前
- 阅读 [README.md](./README.md)
- 查看已有 [Issues](https://github.com/flowlight-ai/flowforge/issues)
- 加入 [Discussions](https://github.com/flowlight-ai/flowforge/discussions)

### 工作流
1. Fork 仓库
2. 创建功能分支: `git checkout -b feat/功能名`
3. 修改代码并测试
4. 提交: `git commit -m "feat: 功能描述"`
5. 推送: `git push origin feat/功能名`
6. 发起 Pull Request (Gitee: dev -> master)

### 提交规范
- `feat:` 新功能
- `fix:` 修复bug
- `docs:` 文档
- `ci:` CI/CD
- `refactor:` 重构
- `test:` 测试
