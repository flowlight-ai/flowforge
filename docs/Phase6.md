### 五、关键风险与应对

| 风险 | 影响 | 应对策略 |
|------|------|---------|
| **市场竞争**：Dify/Coze 等平台也在提供类似能力 | 客户流失、定价被压制 | 差异化：① 9大Agent思维模式是核心壁垒 ② 三件套协同提供「模型+检索+编排」一站式体验 ③ 专注细分场景（内容创作、电商），做深不做广 |

| **Token 成本失控**：大客户调用量超预期 | 利润被侵蚀 | ① 利用 OpenRoute 的「最低成本路由」功能自动选用性价比最优模型 ② 对大客户设置月度 Token 上限 ③ 和客户签订阶梯定价协议 |
| **交付能力瓶颈**：项目太多，团队跟不上 | 交付延期、口碑下滑 | ① 优先做标准化模板（交付周期1-3天），减少定制化项目 ② 培养客户自助使用 FlowForge ③ 和 IT 服务商合作分销，分担交付压力 |
| **开源项目可持续性**：FlowForge 开源后被竞争对手复制 | 壁垒被削弱 | ① 核心壁垒不在代码，而在 9 大 Agent 模式的工程化沉淀和通用 Agent 库的持续积累 ② 模板市场和三件套生态形成网络效应 ③ 保持快速迭代，每月至少发布 1 个新模式或 5 个新 Agent |

### Phase 2：公司实体变更与合规（第3-10天，这是一个持续过程）
**目标**：让“不相关”的公司变成我们的AI公司，并获得经营许可。

#### 2.1 公司信息变更

你要做的是“变更”，不是“新注册”。步骤更简单，在当地市场监督管理局线上或线下办理即可。

| 步骤 | 任务 | 具体做法 | 关键产出 |
| :--- | :--- | :--- | :--- |
| **Step 1** | **名称变更** | 先核名，通过后提交变更申请。将公司名改为你选定的，如“武汉光智泽远人工智能科技有限公司”。 | 《企业名称变更核准通知书》 |
| **Step 2** | **经营范围变更** | 向市监局提交变更申请，用我之前给你的规范清单覆盖所有业务。 | 新《营业执照》 |
| **Step 3** | **章程修改** | 修改公司章程，更新公司名称和经营范围。 | 新《公司章程》 |
| **Step 4** | **银行与税务变更** | 拿新执照，去开户行变更新名称；去税务局变更税务登记信息。 | - |
| **Step 5** | **域名备案** | 用新执照，在云服务器提供商处提交ICP备案。这是国内上线网站的必要条件。 | ICP备案号 |

> **小白提醒**：**变更比新注册快**，通常5-7个工作日可完成。具体流程去你公司注册地所在区的市场监督管理局网站查，或直接去办事大厅问。 **ICP备案必须公司完成变更后才能提交，周期约20个工作日，务必提前做**。

### Phase 3：基础服务部署上线（第10-21天）
**目标**：跑通所有商业服务的MVP，完成ICP备案的提交。

| 任务 | 具体操作 | 产品与方案 |
| :--- | :--- | :--- |
| **1. 购买云服务器** | 1. 购买至少2台云服务器（ECS）：1台生产环境（2核4G以上），1台测试环境。<br>2. 购买域名、对象存储服务（OSS）、CDN。 | **阿里云/腾讯云**：选择“云服务器ECS”，地域选离目标客户近的。 |
| **2. 环境配置** | 1. 搭建 **Docker/Kubernetes** 环境。<br>2. 配置Nginx反向代理，将 `openroute.ai` 指向API服务端口。<br>3. 部署自动化部署流水线（CI/CD）。 | **Docker Compose** (入门) 或 **K3s** (轻量级K8s) |
| **3. 产品部署** | **OpenRoute MVP**：统一API网关，提供文档与免费Key申请。 | 跑通一个API Key管理 + 基础模型路由。 |
| | **OpenSieve MVP**：独立搜索Demo页面，可调用后端API。 | 一个简单的搜索框 + 结果展示页。 |
| | **FlowForge MVP**：打包为SaaS版本，用户可注册登录，创建工作流。 | 包含用户注册、工作流创建、模板导入等基础功能。 |
| **4. 安全与监控** | 1. 配置**HTTPS/SSL证书**（可用Let's Encrypt免费证书）。<br>2. 基础防火墙，防止DDoS攻击。<br>3. 配置服务监控告警。 | **Certbot** (SSL), **Prometheus+Grafana** (监控) |

> **此阶段交付物**：
> 1. `openroute.ai`：能通过API调用模型。
> 2. `opensieve.ai`：能搜索并返回结果。
> 3. `flowforge.ai`：能注册登录，创建一个简单的内容生成工作流。
> 4. 提交ICP备案申请。
