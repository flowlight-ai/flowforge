全局信号：真正可信的自进化不是“让模型反思”，而是把经验按风险逐级固化为 软约束 + 硬护栏 + Eval 证据。

全局信号：面试官不再只问模型 Benchmark，而是在问 Agent + Harness + 环境 + 人类流程的系统级评测。
