## 目标
执行 `flowforge --profile sdk` 起真实 SDK 服务端，用 `python/sdk` 驱动一轮 prompt 至 idle，
验证 Python SDK ↔ TS SDK runtime 端到端链路。

## 现状（勘察结论）
- 客户端侧已齐备：`python/sdk`（28 unittest 全绿）+ TS `@flowforge/sdk-client`（设计孪生），
  默认 spawn `flowforge --profile sdk`（`python/sdk/api.py` `DEFAULT_ARGS = ('--profile','sdk')`）。
- 服务端侧已是**可加载插件** `@flowforge/sdk-jsonrpc-server`（`packages/sdk/server`）——`HarnessSdkJsonRpcServer`
  提供 `initialize`/`session/prompt`/`shutdown` + `session.event`/`session.status`/`subagent.*` 通知，
  stdio 帧由 `JsonRpcLineTransport` 读写 `process.stdin/stdout`。外围 `cordis.yml` 应用示例在
  `packages/examples/jsonrpc-demo`（README 明言）。已有 built-artifact e2e
  `packages/sdk/server/tests/built-scope-carrier.e2e.ts`。
- 已存在 `@flowforge/sdk-app` bundle（`packages/bundle/sdk-app`，寄载 `sdk-jsonrpc-server` + startup provider）。
