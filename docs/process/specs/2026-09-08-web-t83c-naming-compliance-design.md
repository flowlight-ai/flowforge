## 目标（Goal）

把 `web/src/` 中残留的 clowder 品牌词与 P2 别名统一到命名契约的 P0 术语，消除前端命名漂移，为 T8.3a/b（审批流与档案数据真实化）铺平术语地基。

## 架构（Architecture）

- 整改面仅限 `web/src/`（Next.js 前端源码与注释）；`packages/` 后端命名属 EP 线，不在本子项目。
- 三层规则（依据 `docs/design/naming-contract.md:20,32-33,440-441,462`）：
  1. **中文界面文案与注释**：泛指用"智能体"，特指可进化能力用"可进化智能体"。P2 别名"灵智体"仅保留在已括号化的别名位（"可进化智能体（灵智体）"）与社交语境；其余一律转 P0。
  2. **代码标识符/路由/字段名**（`forgekin*`、`cats*`、`bound_forgekins` 等）：一律不动（代码层为 P1，重命名会破坏 API 契约）。
  3. **clowder 品牌词**："猫猫"全部转 P0；对参考源的描述改为"参考 clowder-ai 训练营"（保留出处、去掉品牌词）。
- 不动行为：文案改动不得改变任何渲染逻辑、条件分支与数据绑定。
