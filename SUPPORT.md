## English

### Getting Help

| Channel | Use For | Link |
|---------|---------|------|
| GitHub Issues | Bug reports, feature requests | [New Issue](https://github.com/flowlight-ai/flowforge/issues/new/choose) |
| GitHub Discussions | Questions, ideas, show & tell | [Discussions](https://github.com/flowlight-ai/flowforge/discussions) |
| Documentation | Self-serve knowledge base | [docs/](./docs/) |

### Before Asking for Help

1. **Search existing Issues and Discussions** — your question may already be answered.
2. **Read the documentation** — especially [README.md](./README.md) and [docs/](./docs/).
3. **Check the [CHANGELOG](./CHANGELOG.md)** — the behavior may have changed in a recent release.
4. **Update to the latest version** — `pip install --upgrade flowforge`.

### Filing a Bug Report

Use the [Bug Report template](./.github/ISSUE_TEMPLATE/bug_report.yml) and include:

- FlowForge version (`flowforge --version`)
- Python version (`python --version`)
- Operating system
- Minimal reproduction steps
- Expected vs actual behavior
- Relevant logs (use `CF_DEBUG=1` to enable verbose logging)
- Error traceback

### Reporting Security Vulnerabilities

**Do NOT file security issues as public GitHub Issues.** Instead, see [SECURITY.md](./SECURITY.md) for the responsible disclosure process.

### Commercial Support

For enterprise support, custom integration, or consulting, contact: `flowlight-ai@users.noreply.github.com`

## 中文

### 获取帮助

| 渠道 | 用途 | 链接 |
|------|------|------|
| GitHub Issues | Bug 报告、功能请求 | [新建 Issue](https://github.com/flowlight-ai/flowforge/issues/new/choose) |
| GitHub Discussions | 提问、想法、展示 | [讨论区](https://github.com/flowlight-ai/flowforge/discussions) |
| 文档 | 自助知识库 | [docs/](./docs/) |

### 提问之前

1. **搜索现有的 Issues 和 Discussions** — 你的问题可能已有答案。
2. **阅读文档** — 特别是 [README.md](./README.md) 和 [docs/](./docs/)。
3. **检查 [CHANGELOG](./CHANGELOG.md)** — 行为可能在最近版本中已变更。
4. **更新到最新版本** — `pip install --upgrade flowforge`。

### 提交 Bug 报告

使用 [Bug 报告模板](./.github/ISSUE_TEMPLATE/bug_report.yml)，并包含：

- FlowForge 版本（`flowforge --version`）
- Python 版本（`python --version`）
- 操作系统
- 最小复现步骤
- 期望与实际行为
- 相关日志（使用 `CF_DEBUG=1` 开启详细日志）
- 错误堆栈

### 报告安全漏洞

**请勿将安全问题作为公开的 GitHub Issue 提交。** 请参阅 [SECURITY.md](./SECURITY.md) 了解负责任的披露流程。

### 商业支持

如需企业支持、定制集成或咨询服务，请联系：`flowlight-ai@users.noreply.github.com`
